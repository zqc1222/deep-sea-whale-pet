在「打赏作者」区块加入两道防线，防止山寨版偷换收款码：

- **下载提示**：明确提醒用户只从官方 GitHub Release 下载，并在使用前核对内容指纹。

  - **不一致** → 内容已发生变化，请立即停止使用并重新从官方下载。

## 说明

- 内容指纹只对打包版生效；浏览器演示 / 开发版不显示。
- 内容指纹只能用于比对 `app.asar` 内容，不能验证发布者身份，也不能替代 Authenticode 代码签名。
- 下载提示与内容指纹不改变任何打赏流程，只是多一道内容核对。
