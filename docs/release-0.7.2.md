# 深海鲸灵 0.7.2

## 历史功能与说明更正

该版本在「打赏作者」区块加入下载来源提示与应用内短指纹。旧界面将其称为“正版校验码”，但这个名称和“一致即为官方版本”的描述过强，现更正如下。

- 显示值是 `resources/app.asar` 的 SHA-256 前 12 位，只能辅助对比该文件内容。
- 应用自身的指纹显示逻辑可以被修改，指纹一致不能单独证明发布者身份或收款码真实性。
- 指纹不覆盖整个安装包或 Electron 运行文件，不能替代在应用外检查完整 `.exe` 的 SHA-256。
- 打包后的安装版和便携版均可在读到 `app.asar` 时提供指纹；开发模式不提供。读取失败应显示失败状态。

历史发布记录中的短指纹为 `2D37A9219133`，此次文档修订未重新验证历史安装包。它不适用于修改源码后的新构建。

具体操作和可信来源的限制见[下载核验指南](VERIFY-DOWNLOAD.md)。

## 历史验证记录

原发布说明记录了 TypeScript 检查、Electron 生产构建，以及构建目录中 `app.asar` 指纹的检查。这些是原发布的记录，不是本次文档修订重新运行所得的结果。

## 安装说明

- 安装版：`DeepSeaWhalePet-Setup-0.7.2-x64.exe`。
- 便携版：`DeepSeaWhalePet-Portable-0.7.2-x64.exe`。
- 历史包没有配置代码签名，Windows SmartScreen 可能显示“未知发布者”。

本次源码和文档修订不会修改已发布的二进制文件；旧安装包仍可能显示旧措辞。新构建发布时需要生成新的完整 SHA-256 清单，不能覆盖或沿用旧包的校验值。

这是非官方同人概念原型，与 DeepSeek 官方无隶属、授权或背书关系。
