# 深海鲸灵 0.2.0

## 本次更新

- 保留 0.1.1 的原创主立绘和全部待机微动。
- 新增“想吃白饭、趴睡、认真思考、任务板工作”四套同角色透明状态素材。
- 桌宠待机时自动随机演出性格状态；聊天与专注面板会显示对应形态。
- 右侧快捷栏改为靠近角色时浮现，并加入手动状态轮播按钮。
- 拖拽时快捷栏立即隐藏，窗口移动采用帧批处理并主动刷新 Chromium 合成层，避免角色与工具栏出现视觉分离。

## 已验证

- 四套素材已完成透明边缘与主体完整性检查。
- 浏览器演示模式已检查桌宠、聊天和专注三种布局。
- TypeScript 严格类型检查与 Electron 构建通过。
- Windows x64 安装版与便携版打包成功，文件版本均为 0.2.0。
- 最终便携版已实际启动；两次真实窗口拖拽的坐标变化与模拟位移完全一致。

## 安装说明

- 安装版：运行 `DeepSeaWhalePet-Setup-0.2.0-x64.exe`，可选择安装目录。
- 便携版：直接运行 `DeepSeaWhalePet-Portable-0.2.0-x64.exe`。
- 当前没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。

这是原创非官方同人概念原型，与 DeepSeek 官方无隶属、授权或背书关系。
