# 深海鲸灵 0.6.0

## 本次更新：主动关怀

桌宠醒着的时候，每隔一段时间会主动"看一眼"你在做什么，然后搭话：

- **随机间隔**：默认 1.5~2 小时（每次触发后重新随机 ±15%），可选 1 小时 / 3 小时。
- **"看"的方式**：读取前台窗口标题和系统空闲时长——纯本地，不截屏、不记录、不上传。
- **它会说什么**（按看到的内容分类）：
  - 离开 5 分钟以上："你好像离开了一会儿…我帮你守着桌面。"
  - 写代码（VS Code / IDEA / PyCharm / 终端…）："看到你在写代码…这个思路应该能走通，加油。"
  - 逛浏览器（Chrome / Edge / B站…）："逛到好东西了吗？记得喝口水。"
  - 打游戏（Steam / 原神 / LOL…）："劳逸结合，赢一局就起来走走。"
  - 文档办公（Word / Excel / WPS…）："文档改得怎么样了？眼睛歇一歇。"
  - 看视频听歌：'看得很投入嘛…别熬太晚。'
  - 读不到窗口："还在忙吗？我替你看着时间。"
- **不打扰原则**：睡眠时段自动安静；聊天/专注/设置面板打开时不触发。
- **设置**：设置页新增"主动关怀"（开关 + 间隔三档），隐私说明一并注明。
- **演示调试**：浏览器模式 `?care=20` 缩短到 20 秒触发一次，`?window=code` 模拟"看到编程"。

## 已验证

- TypeScript 严格类型检查与 Electron 生产构建通过。
- 前台窗口探测实机验证：正确读取当前活动窗口标题（UTF-8 编码处理）。
- 空闲时长通过 powerMonitor 获取，读取失败自动降级为通用台词。
- 睡眠时段、面板模式下不触发；触发后重新随机计时。

## 安装说明

- 安装版：运行 `DeepSeaWhalePet-Setup-0.6.0-x64.exe`，可选择安装目录。
- 便携版：直接运行 `DeepSeaWhalePet-Portable-0.6.0-x64.exe`。
- 当前没有商业代码签名证书，Windows SmartScreen 可能显示"未知发布者"。

这是原创非官方同人概念原型，与 DeepSeek 官方无隶属、授权或背书关系。
