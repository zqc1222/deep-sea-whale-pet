# 深海鲸灵 0.7.3

## 本次更新：天气修复与发布信息校正

- 关闭「跟随天气」或清空天气地点后，立即清除旧天气缓存并推送未连接状态，不再残留雨雪特效、温度徽章或天气台词。
- 渲染层同时检查天气开关，即使状态推送延迟，也会立刻停止天气视觉与语音效果。
- 设置页将容易误解的「正版校验码」改为「内容指纹」，明确它用于比对发布产物内容，不能替代系统代码签名。
- 同步 `package.json` 与 `package-lock.json` 的 0.7.3 版本号。
- Windows 安装包、快捷方式和开始菜单使用新版“鲸尾 + 珍珠 + 声呐环”应用图标。

## 内容指纹

`resources/app.asar` 的 SHA-256 前 12 位：

```text
9497E20E7DE7
```

该指纹只能说明当前 `app.asar` 内容是否与本 Release 公布值一致，不能验证发布者身份。当前项目未配置商业 Authenticode 证书，Windows SmartScreen 仍可能显示“未知发布者”。

## 安装说明

- 安装版：运行 `DeepSeaWhalePet-Setup-0.7.3-x64.exe`，可选择安装目录。
- 便携版：直接运行 `DeepSeaWhalePet-Portable-0.7.3-x64.exe`。

这是原创非官方同人概念原型，与 DeepSeek 官方无隶属、授权或背书关系。
