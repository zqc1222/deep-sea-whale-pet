# 深海鲸灵 0.2.1

## 本次更新

- “想吃白饭、趴睡、认真思考、任务板工作”四种状态现在都会配上对应短句。
- 每种状态内置三句随机文案，重复进入时会自然轮换，避免每次都说同一句。
- 气泡新增“饭点信号、休眠漂流、思考水域、专注航线”状态标签，并使用对应强调色。
- 状态文案出现约 5.2 秒后自动收起；回到待机时同步清理，不残留旧状态文字。
- 保留 0.2.0 的原创主立绘、四套状态造型、待机微动、快捷栏和拖拽修复。

## 已验证

- 四种状态均已通过浏览器演示模式视觉检查，标签与长句换行不会遮挡角色。
- TypeScript 严格类型检查与 Electron 生产构建通过。
- Windows x64 安装版与便携版打包成功，文件版本均为 0.2.1。
- 最终便携版已实际启动检查。

## 安装说明

- 安装版：运行 `DeepSeaWhalePet-Setup-0.2.1-x64.exe`，可选择安装目录。
- 便携版：直接运行 `DeepSeaWhalePet-Portable-0.2.1-x64.exe`。
- 当前没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。

这是原创非官方同人概念原型，与 DeepSeek 官方无隶属、授权或背书关系。
