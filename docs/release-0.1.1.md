# 深海鲸灵 0.1.1

## 本次更新

- 待机时持续上下漂浮，并叠加独立的轻呼吸缩放。
- 新增与漂浮同步、但反向补偿位移的动态地面阴影。
- 气泡扩展为五组不同周期与路径，减少机械重复感。
- 每隔约 3.2–6.8 秒随机眨眼，并有小概率连续眨两次。
- 每隔约 7.6–14.8 秒随机轻微左偏、右偏或抬头，然后平滑恢复。
- 窗口隐藏、切换到其他状态或开启“减少动态效果”时，待机随机动作会暂停。

## 已验证

- TypeScript 严格类型检查通过。
- Electron 主进程、preload 与 React 渲染页面构建通过。
- 使用实际 Chromium 合成结果录制了 66 帧动态预览，并检查眨眼遮罩位置。
- Windows x64 安装版与便携版打包成功，文件版本均为 0.1.1。

## 安装说明

- 安装版：运行 `DeepSeaWhalePet-Setup-0.1.1-x64.exe`，可选择安装目录。
- 便携版：直接运行 `DeepSeaWhalePet-Portable-0.1.1-x64.exe`。
- 当前没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。

这是原创非官方同人概念原型，与 DeepSeek 官方无隶属、授权或背书关系。
