# 深海鲸灵 0.5.1

## 本次更新：下雨效果重做（Canvas 粒子系统）

0.5.0 的雨是用 CSS 平铺渐变实现的，看起来像规则的屏幕纹理。0.5.1 重写为真正的 Canvas 2D 粒子系统：

- **620 个随机雨滴**：每滴的长度、宽度、透明度、速度独立随机，近处粗长亮快、远处细短淡慢，形成自然景深。
- **风向倾斜**：全局风速 + 每滴独立扰动，倾斜角按每滴的速度比单独计算，不再有平行竖线。
- **镜头雨滴**：42 个前景大雨滴（更长更快更亮）随机分布，模拟摄像机附近的雨。
- **淡入淡出**：每滴出生时 0.5 秒淡入，不会突然出现。
- **落地水花**：雨滴落地溅起细碎水花，受重力回落消失。
- **湿润地面**：底部蓝白湿润光带，模拟水坑反射。
- **阴天氛围**：角色后方雾霭 overlay + 角色阴天滤镜（压暗、降饱和、蓝白微光）。
- 主雨在角色之后（不遮挡桌宠），镜头雨在前但细淡；"减少动画"开启时不渲染。
- 保持 60fps，粒子全部走 requestAnimationFrame。

## 已验证

- TypeScript 严格类型检查与 Electron 生产构建通过。
- 演示 `?weather=rain`：随机雨滴、风向倾斜、三层景深、落地水花、湿润地面、阴天滤镜均正常。
- 减少动画开启时不渲染粒子。
