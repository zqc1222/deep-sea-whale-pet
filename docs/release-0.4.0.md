# 深海鲸灵 0.4.0

## 本次更新：作息时间驱动行为

桌宠现在会按照本地时间过自己的生活：

- **夜间自动入睡**（默认 21:00 – 08:00）：到点后会打起瞌睡、冒出 Z 字、整体沉浸进夜晚氛围，随机动作与眨眼全部暂停。
- **点一下才会醒来**：睡觉时单击它，会伸个懒腰醒过来；双击直接唤醒并打开聊天；拖动也会把它叫醒。
- **唤醒豁免期**：被唤醒后默认保持清醒 15 分钟（可调 5–60 分钟），期间不会再睡着；豁免期结束后若仍在深夜，它会说句"哈啊……那再眯一会儿"重新入睡。豁免状态跨重启保留。
- **清晨问候**：起床后 90 分钟内是"清晨"时段，桌宠以清醒状态迎接新的一天。
- **饭点想吃白饭**：午（11:30–13:30）晚（17:30–19:00）两餐时间会提示饿肚子。
- **作息可配置**：设置页新增"作息活动"，可开关作息、自定义入睡/起床时间、唤醒豁免时长，饭点提示也可单独关闭。
- **浏览器演示支持 `?time=HH:MM`**：例如 `http://127.0.0.1:5173/?time=23:40` 可直接预览深夜睡眠效果。

## 已验证

- TypeScript 严格类型检查与 Electron 生产构建通过。
- `?time=23:40` 演示：自动入睡、Z 字动画、夜晚滤镜、随机轮播与眨眼暂停。
- 睡眠中单击唤醒并播放唤醒台词；豁免期内不入睡；豁免期后自动回到睡眠。
- `?time=08:00` 清晨问候、`?time=12:00` 饭点提示均正常触发。
- 关闭作息开关后全天保持现有随机行为。
- 旧版本配置文件无新字段时自动补齐默认作息，不报错。

- 便携版：直接运行 `DeepSeaWhalePet-Portable-0.4.0-x64.exe`。
