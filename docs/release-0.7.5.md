# 深海鲸灵 0.7.5

## 本次更新：聊天复制与本地存档

- 聊天消息正文可以用鼠标选中，并通过 `Ctrl+C` 复制。
- 每条用户消息和鲸灵回复都新增“一键复制”按钮，算法与代码可以完整复制到编辑器。
- 最近 100 条聊天记录自动写入本机应用数据，关闭桌宠或重启电脑后仍可恢复。
- 单条记录最多保存 20,000 个字符，兼顾较长代码与存储体积。
- 频道顶部显示“对话本地保存”，并提供带二次确认的“清空记录”按钮。
- 浏览器演示模式也会使用浏览器本地存储保留聊天记录。

聊天正文不会因为本功能自动上传；API 模式下，只有正常发起模型请求时才会把当前上下文发送到用户配置的接口。
