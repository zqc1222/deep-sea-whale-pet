# 下载与完整性核对

## 先确认发布来源

从维护者仓库的 [Releases](https://github.com/zqc1222/deep-sea-whale-pet/releases) 选择版本，下载安装版或便携版，以及该版本的 SHA-256 清单（旧版本可能命名为 `DeepSeaWhalePet-SHA256SUMS-版本.txt`）。确认仓库所有者是 `zqc1222`，仓库名是 `deep-sea-whale-pet`。

## 在应用外核对整个安装文件

在 PowerShell 中运行，路径替换为你实际下载的文件：

```powershell
Get-FileHash -LiteralPath 'C:\Downloads\DeepSeaWhalePet-Setup-0.7.2-x64.exe' -Algorithm SHA256
```

将输出的完整 64 位十六进制 Hash 与可信发布页取得的清单中**同名文件**的值逐位比较（大小写不影响比较）。安装版与便携版的 Hash 不同，各版本也不同。

- 相同：表明下载文件与该清单记录的文件一致。
- 不同：不要继续运行，重新确认版本、文件名及下载来源。

这依赖你取得的清单可信。攻击者若同时替换程序和清单，单靠 Hash 对比无法认证发布者身份；Hash 也不是对软件无漏洞的保证。

## 应用内短指纹的用途与限制

设置页显示的“应用文件指纹”是 `resources/app.asar` 的 SHA-256 **前 12 位**，用于辅助对比构建内容。它不是安装程序整个 `.exe` 的 Hash，不覆盖 Electron 可执行文件及其他打包文件。

指纹由应用自身计算并显示；被修改的应用也能伪造这个显示结果。因此，指纹一致不能单独证明程序来自维护者，也不能保证收款码真实。打赏前应另行核实收款人。

历史 v0.7.2 发布记录中的短指纹是 `2D37A9219133`，仅供该历史构建参考，未在此次文档修订中重新验证。修改源码后重新构建会产生新的指纹，不能沿用旧值。后续发布应重新生成安装文件的完整 SHA-256 清单。

开发模式不提供该指纹；打包后的安装版和便携版在能够读取 `app.asar` 时均可提供。读取失败不代表当前是开发版。

当前历史发布没有配置代码签名。Windows 可能显示“未知发布者”；应用内指纹不能替代操作系统的发布者签名验证。
