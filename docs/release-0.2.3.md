# 深海鲸灵 0.2.3

## 本次更新

- 设置页新增“本地模式 / API 模式”显式切换，不再仅根据是否填写 API 配置自动判断。
- 本地模式完全使用内置陪伴回复，不消耗 Token；API 模式使用已配置的 OpenAI-compatible 模型。
- 切回本地模式会保留 Base URL、模型名和加密 API Key，之后可直接切回 API 模式。
- API 模式资料不完整时会明确提示，不会静默退回本地回答。
- 桌宠大小改为数值输入，支持 50%–200% 的任意整数比例，并实时显示对应窗口像素尺寸。
- 保留 80%、100%、120%、150% 四个常用快捷尺寸；收起设置面板后应用新大小。
- 旧版本中已经配置完整 API 的用户会自动迁移为 API 模式，原有密钥无需重新输入。

## 已验证

- 本地模式与 API 模式两种设置页状态完成视觉检查。
- 自定义 137% 能正确换算为 493 × 685 px。
- 主进程会再次校验模式值和 50%–200% 尺寸范围。
- TypeScript 严格类型检查与 Electron 生产构建通过。
- Windows x64 安装版与便携版打包成功，文件版本均为 0.2.3。

## 安装说明

- 安装版：运行 `DeepSeaWhalePet-Setup-0.2.3-x64.exe`，可选择安装目录。
- 便携版：直接运行 `DeepSeaWhalePet-Portable-0.2.3-x64.exe`。
- 当前没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。

这是原创非官方同人概念原型，与 DeepSeek 官方无隶属、授权或背书关系。
