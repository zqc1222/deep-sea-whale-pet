# 深海鲸灵 0.5.0

## 本次更新：天气感知 + 羁绊养成

**🌦️ 天气感知（设置页开启）**
- 桌宠会跟随外面的天气换心情：晴天晒尾巴、雨天阴沉提醒带伞、雪天看雪、打雷吓得尾巴竖起来。
- 天气从 Open-Meteo 免费接口获取，无需任何 Key；填写城市名（如 `Qinhuangdao`）或经纬度（如 `39.93,119.60`）即可。
- 降温提醒：气温低于 10°C 时会提醒加衣。
- 天气每 60 分钟自动刷新一次；网络失败自动静默降级，绝不影响桌宠本体。
- 浏览器演示支持 `?weather=rain` 直接预览雨雪雷晴效果。

**🐳 羁绊养成**
- 桌宠会记住陪伴天数与累计专注时长，跨天自动累计。
- 里程碑系统：初遇（1 天）、一周守望（7 天）、满月（30 天）、百日灯塔（100 天）、静潜初航（专注 1 小时）、静潜大师（10 小时）、深海领航员（50 小时）。达成时它会弹专属台词，只弹一次。
- 专注计时每完成一轮（25 分钟）自动计入羁绊。
- 设置页新增"羁绊档案"：实时展示陪伴天数、累计专注和全部里程碑解锁进度。
- 数据保存在本机，与 API Key 一样由主进程安全持久化。

## 已验证

- TypeScript 严格类型检查与 Electron 生产构建通过。
- 天气：Open-Meteo 地理编码 + 预报接口拉取成功，WMO 天气代码正确映射；失败时静默降级为未连接。
- 演示：`?weather=rain` 雨丝粒子、`?weather=snow` 雪花、`?weather=thunder` 闪电闪烁、`?weather=clear` 暖光滤镜均生效，切换天气触发一次台词。
- 羁绊：跨天陪伴天数 +1、专注完成累计、里程碑只触发一次并持久化。
- 设置页天气开关与城市保存、羁绊档案展示正常。
