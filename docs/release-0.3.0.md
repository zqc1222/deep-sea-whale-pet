# 深海鲸灵 0.3.0

## 本次更新

- 新增原创鲸鱼少年主角，并保留原有鲸鱼少女。
- 设置页新增“鲸鱼娘 / 鲸鱼少年”形象切换卡；保存后选择会持久化，旧用户默认继续使用女版。
- 男主拥有待机、饿了、困倦、思考和任务板工作五套透明状态素材。
- 两位角色共用同一套自动状态轮播、手动轮播、点击、拖拽、聊天思考形态、专注工作形态、气泡短句和减少动画逻辑。
- API 模式的系统人设会依据当前角色使用“鲸鱼少女”或“鲸鱼少年”称谓。
- 浏览器演示支持通过 `?gender=female` 或 `?gender=male` 直接检查角色形态。

## 已验证

- 男主五张素材均为 1254 × 1254、带 Alpha 的透明 PNG，四角 Alpha 为 0。
- 设置页男女选择状态及左侧角色预览完成 Chromium 截图检查。
- 男主待机、饿了、困倦、思考、工作五种形态均完成桌宠实际布局截图检查，无裁切或越界。
- TypeScript 严格类型检查与 Electron 生产构建通过。
- Windows x64 安装版与便携版打包成功，文件版本均为 0.3.0；便携版已实际启动检查。

## 安装说明

- 安装版：运行 `DeepSeaWhalePet-Setup-0.3.0-x64.exe`，可选择安装目录。
- 便携版：直接运行 `DeepSeaWhalePet-Portable-0.3.0-x64.exe`。
- 当前没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。

这是原创非官方同人概念原型，与 DeepSeek 官方无隶属、授权或背书关系。
