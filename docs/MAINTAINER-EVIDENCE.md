## 申请表英文草稿（项目资格说明）

I maintain DeepSea Whale Pet, a Windows desktop companion with focus sessions, optional API chat and local chat history. Based on my own estimate, more than 20 classmates have used it for about two months and still use it; this is not independently measured active-user data. I develop features, fix weather and tray issues, and package Windows releases. The project has public source code, licensing documentation and release notes.
