# 深海鲸灵 0.7.1

## 本次更新：天气感知修复与天气语音

修复天气功能并带来更完整的天气体验：

- **修复**：坐标解析支持全角逗号（`，`）等中文标点，中文输入法填写的 `纬度，经度` 也能正常定位（之前会导致天气永远连接失败）。
- **修复**：保存天气设置后立即刷新并显示天气，不再需要等待最长 10 分钟的轮询。
- **新增**：右上角天气温度徽章，显示 `温度°C · 天气`（如 `20°C · 雨`），圆点颜色随天气变化。
- **新增**：天气专属语音——晴/多云/雨/雪/雷雨各有 4 句专属台词，天气切换时随机冒一句，天气持续期间每隔 6~13 分钟也会随机冒一句。
- **提示**：温度低于 10°C 时鲸灵会带寒冷色调，并在降温时提醒保暖。

## 已验证

- TypeScript 严格类型检查与 Electron 生产构建通过。
- 全角逗号 `48.44，123.43` 归一化为 `48.44,123.43` 后定位成功（实机天气：阵雨 20.3°C）。
- 主进程天气刷新完成后主动推送，渲染层即时显示温度徽章与天气台词。
- 天气语音在浏览器演示模式可用 `?weather=rain&weathervoice=8` 加速预览。
