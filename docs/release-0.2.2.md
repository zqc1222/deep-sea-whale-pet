# 深海鲸灵 0.2.2

## 本次修复

- 修复长对话将聊天面板整体撑高、导致消息无法继续向下滚动的问题。
- 消息列表现在是独立的纵向滚动区域，并显示细窄的深海蓝滚动条。
- 新消息和模型回复完成后，会在布局刷新后可靠地滚动到最新内容。
- 输入框与底部功能导航固定在窗口内，不再被长消息挤出可视区域。
- 左侧角色所在网格行锁定为窗口高度，角色不会再随右侧内容跑到窗口下方。

## 已验证

- 使用 760 × 570 逻辑像素窗口和 11 条长短混合消息进行视觉压力测试。
- 滚动区的内容高度超过可视高度时能够正常滚动到底部。
- 左侧思考状态角色、右侧输入框和底部区域保持可见。
- TypeScript 严格类型检查与 Electron 生产构建通过。
- Windows x64 安装版与便携版打包成功，文件版本均为 0.2.2。

## 安装说明

- 安装版：运行 `DeepSeaWhalePet-Setup-0.2.2-x64.exe`，可选择安装目录。
- 便携版：直接运行 `DeepSeaWhalePet-Portable-0.2.2-x64.exe`。
- 当前没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。

这是原创非官方同人概念原型，与 DeepSeek 官方无隶属、授权或背书关系。
