# 深海鲸灵 0.7.0

## 本次更新：打赏作者

设置页新增「打赏作者」区块，如果喜欢这只小鲸鱼，可以扫一扫请作者喝杯奶茶：

- **入口**：设置面板 → 右侧栏底部「打赏作者」（编号 09）。
- **内容**：收款二维码 + 一句感谢文案 + 温馨提示。
- **自愿原则**：打赏完全自愿，理性消费、量力而行；不打赏也完全不影响使用。
- **隐私**：仅展示静态收款码，不采集、不记录、不上传任何打赏相关数据；收款由第三方支付渠道完成，与应用本身无关。
- **体积**：收款码图片压缩至 600px 宽，安装包相对 0.6.0 仅增加约 72KB。

## 已验证

- TypeScript 严格类型检查与 Electron 生产构建通过。
- 打赏区块为纯静态展示：无状态、无 IPC、无持久化，不影响现有设置项。
- 打赏功能已随 0.7.0 打包进 NSIS 安装版与便携版。

## 安装说明

- 安装版：运行 `DeepSeaWhalePet-Setup-0.7.0-x64.exe`，可选择安装目录。
- 便携版：直接运行 `DeepSeaWhalePet-Portable-0.7.0-x64.exe`。
- 当前没有商业代码签名证书，Windows SmartScreen 可能显示"未知发布者"。
- 建议安装后先在设置页确认收款码扫码有效。

这是原创非官方同人概念原型，与 DeepSeek 官方无隶属、授权或背书关系。
